# Calculadora de Desconto

Programa em Python que calcula o valor do desconto e o preço final de uma compra, com base no valor total informado pelo usuário.

## Como funciona

O usuário digita o valor da compra e o programa aplica um desconto de acordo com as seguintes regras:

| Valor da compra                  | Desconto |
|-----------------------------------|----------|
| Menor que R$ 200,00                | 5%       |
| Maior ou igual a R$ 200,00 e menor que R$ 300,00 | 10%      |
| Maior ou igual a R$ 300,00          | 15%      |
